# Windows 修改本地账户密码（WinToolbox）

在 **本地账户** 页为指定本地用户修改密码，并可同步加强密码策略与账户锁定。

## 配图标注

![修改密码操作标注](./images/06-change-password.svg)

| 标注 | 界面选项 | 说明 |
|------|----------|------|
| ① | **用户** | 选择要改密的本地账户 |
| ② | **新密码** | 输入新密码 |
| ③ | **确认密码** | 再次输入，须与 ② 一致 |
| ④ | **修改密码** | 提交更改（有确认框） |

账户页其它相关选项见总览图：

![本地账户完整标注](./images/02-account-ops.svg)

| 标注 | 界面选项 | 与改密的关系 |
|------|----------|--------------|
| ③ | **应用密码策略** | 提高全机最短长度与复杂度，改密前/后均可 |
| ④ | **一键开启锁定** | 防暴力猜解，建议与强密码一起启用 |
| ①② | **禁用来宾 / 关闭自动登录** | 减少弱入口，改密后仍建议执行 |

## 操作步骤

1. 管理员运行 WinToolbox → 侧栏 **本地账户**。
2. 在 **账户操作** 中选择用户（①）。
3. 填写 **新密码**（②）与 **确认密码**（③）。
4. 点击 **修改密码**（④）并确认。
5. 建议接着：
   - **应用密码策略**（例如最短长度 12）
   - **一键开启锁定**
   - 用新密码实际登录验证一次

## 密码建议

- 长度 ≥ 12（服务器建议 ≥ 14）
- 包含大小写字母、数字、符号
- 勿与主机名、用户名、旧密码高度相似
- 改密后更新保存在密码管理器 / 运维文档中的凭据

## 注意事项

- 不能通过本工具把「当前登录用户」设为禁用或取消管理员（防锁死）。
- 域账户密码通常由域控管理；本页面向**本地账户**。
- 若开启了自动登录，改密后请 **关闭自动登录**，避免明文密码残留。
