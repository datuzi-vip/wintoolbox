# Windows 修改远程桌面端口（WinToolbox）

将默认 RDP 端口（3389）改为非常用端口，并同步防火墙与 NLA，降低扫描与爆破命中率。

## 配图标注

![远程桌面改端口操作标注](./images/03-rdp-port.svg)

| 标注 | 界面选项 | 说明 |
|------|----------|------|
| ① | **端口** | 输入目标端口（1–65535），避开已被占用的端口 |
| ② | **保存端口** | 写入系统设置，并创建/更新 `WinToolbox-RDP` 入站放行规则 |
| ③ | **开启 / 关闭** | 确认远程桌面服务处于「已开启」 |
| ④ | **强制 NLA** | 建议开启；极旧客户端可能无法连接 |

## 操作步骤

1. 以管理员运行 **WinToolbox**，打开侧栏 **远程桌面**。
2. 在 **端口**（①）填入新端口，例如 `45980`。
3. 点击 **保存端口**（②），在确认框中确认。
4. 若状态为已关闭，点击 **开启**（③）。
5. 点击 **强制 NLA**（④）。
6. 在客户端用 `计算机名或IP:新端口` 测试，例如 `192.168.1.10:45980`。
7. 云主机请同步修改**安全组 / 防火墙入站规则**到新端口。

## 注意事项

- 保存端口成功后，旧 3389 放行规则不一定自动删除；公网场景请检查安全组是否仍放行 3389。
- 状态显示「不可用」时，可能未安装远程桌面服务或权限不足。
- NLA 状态为「未知」时，先点窗口右上角 **刷新** 再操作。
