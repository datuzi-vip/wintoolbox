# Windows 关闭 / 恢复系统更新（WinToolbox）

通过 WinToolbox **系统更新** 页一键暂停或恢复 Windows Update（策略 + 相关服务）。适用于临时运维窗口，不建议作为长期安全策略。

## 第一步：下载软件

1. 打开最新版下载页：https://github.com/datuzi-vip/wintoolbox/releases/latest  
2. 下载 **`WinToolbox-v*.exe`**。  
3. 若浏览器提示「已阻止 / 不安全」，展开菜单后点 **保留** / **保持**（Keep）；仍提示风险时选 **仍要保留**。  
4. 双击运行；若出现 SmartScreen，点 **更多信息 → 仍要运行**。  
5. 在 UAC 中允许，**以管理员身份**打开本工具。

更多说明见：[下载 WinToolbox](./download.md)

| 标注 | 界面选项 | 说明 |
|------|----------|------|
| ① | **关闭更新** | 先把当前更新策略与相关服务启动类型写入本工具的**配置备份**，再禁用更新 |
| ② | **恢复更新** | 优先按上述配置备份还原；成功后清除备份（**不是**云主机/虚拟机磁盘快照） |

## 配置备份是什么（勿与服务器快照混淆）

这里说的「配置备份」只保存在本机注册表（`WinToolbox` 自己的备份键）里，内容大致包括：

- Windows Update 相关策略值（如 `NoAutoUpdate`）
- 若干更新服务的启动类型（如 `wuauserv`、`UsoSvc` 等）

它**不会**：

- 做整机/磁盘镜像
- 回滚文件、应用或系统还原点
- 等同于云厂商控制台里的「服务器快照 / 云盘快照」

因此「恢复更新」= 尽量把更新相关设置改回**你点关闭更新之前**的状态，而不是整机回档。

## 关闭更新

1. 完成上文「第一步：下载软件」，管理员运行 WinToolbox → 侧栏 **系统更新**。  
2. 确认状态不是「未知」（必要时先刷新）。  
3. 点击 **关闭更新**（①），确认操作。  
4. 等待状态变为 **已关闭**，明细中可见策略与服务状态。  

## 恢复更新

1. 在同一页面点击 **恢复更新**（②）。  
2. 确认状态回到 **运行中**。  
3. 如需立刻检查更新，可再到系统「设置 → Windows 更新」手动检查。  

## 注意事项

- **域 / Intune / WSUS** 等管理策略可能覆盖本机设置。
- 关闭后仍可能收到部分累积更新以外的提醒；以本页状态明细为准。
- 长期关闭会显著增加安全风险；加固基线请参考 [系统加固指南](./windows-hardening.md)，常态应保持更新可用。
- 若从未用本工具执行过「关闭更新」，或备份已清除，恢复会走默认安全配置，而不是某次云主机快照。
